자주 묻는 질문

어떤 데이터를 볼 수 있나요?

상권 탐색은 공식 API의 점포 응답을, 카드매출 분석은 제공기관의 통계와 적재된 자료를 표시합니다.

왜 실제 추천 점수가 보이지 않나요?

실제 추천 점수에는 비교 가능한 통계와 점포 데이터의 적재·검증이 필요합니다. 현재 실데이터 모드에서는 확인된 점포와 공식 통계를 조회할 수 있습니다.

공유 링크에서도 가입과 API 조회가 되나요?

가입·관리자·실제 API를 사용하려면 Node.js 서버를 HTTPS로 배포하고 환경변수를 설정해야 합니다.

내 정보는 어디에 저장되나요?

서버 가입 시 이름·이메일·비밀번호 해시와 저장한 조건이 서버 SQLite 데이터베이스에 저장됩니다. 비밀번호 원문은 저장하지 않으며, 로그인 쿠키는 JavaScript에서 읽을 수 없습니다. 이메일 인증과 비밀번호 재설정 메일은 아직 제공하지 않습니다.
